HealthTrack 🏥

HealthTrack es un sistema orientado a la gestión de historiales clínicos, diseñado para permitir el registro, consulta y administración organizada de información médica de los pacientes.

📋 Descripción

El proyecto busca facilitar la gestión de información clínica mediante una aplicación que permita almacenar y consultar los historiales médicos de forma estructurada.

Entre las principales funcionalidades contempladas se encuentran:

Gestión de pacientes.
Registro de historiales clínicos.
Consulta de información médica.
Actualización de registros clínicos.
Administración de información almacenada en la base de datos.
🛠️ Tecnologías utilizadas
Tecnología	Uso
TypeScript	Lenguaje principal del proyecto
PostgreSQL	Base de datos
Git	Control de versiones
GitHub	Repositorio y colaboración
🗄️ Base de datos

El proyecto utiliza PostgreSQL como sistema de gestión de bases de datos.

La base de datos está destinada a almacenar la información relacionada con:

Pacientes.
Historias clínicas.
Consultas médicas.
Antecedentes y registros médicos.
